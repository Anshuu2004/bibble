## 💌 A little note from me

I made **Bibble** because I wanted learning to feel a little less lonely and a lot less overwhelming. I picture it as a cozy online table: you bring whatever you're curious about, settle in for a gentle focus session, and turn the things you learn into a map you can keep growing.

I love the idea that progress doesn't have to be loud or perfect. One small study session, one new connection, one little **bibble** at a time. 💗

This is my early front-end version of that idea. It doesn't have a backend yet, so the rooms, people, and example maps are sample content—not live shared spaces. Maps you create are saved in your own browser.

## 🏡 Make yourself at home

You'll need [Node.js](https://nodejs.org/) and npm. Then, from your terminal:

```bash
git clone https://github.com/anshika-guleria/bibble.git
cd bibble
npm install
npm run dev
```

Now open [http://localhost:3000](http://localhost:3000) and come on in. ☕
