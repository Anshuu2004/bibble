# 🍓 Bibble

### A cozy little space to grow what you know.

Bibble is a soft, friendly learning space for exploring study rooms and turning what you learn into visual maps. Pull up a chair, find a topic, and take things one small step at a time. ☁️

> **Please note:** Bibble is a front-end project and does not have a backend yet. Rooms, participants, and example maps use sample data. Maps you create are saved in your browser.

## ✨ What you can do

- 🪴 Browse and search cozy study rooms
- 🗺️ Explore sample learning maps
- 🍵 Create a learning map and keep it in your browser
- ⏳ Settle in with a focus timer and ambient sound
- 🎨 Make the space your own with gentle themes

## 🧸 A peek around

| Page | What you'll find |
| --- | --- |
| **Home** | A warm welcome and a preview of Bibble |
| **Study rooms** | Sample rooms for different topics and moods |
| **Explore** | Example learning maps to browse |
| **Create** | A simple way to start your own learning map |

## 🚀 Run Bibble on your computer

You'll need [Node.js](https://nodejs.org/) and npm.

```bash
git clone https://github.com/anshika-guleria/bibble.git
cd bibble
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to visit Bibble.

## 🛠️ Built with

- [Next.js](https://nextjs.org/) and [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [XYFlow](https://xyflow.com/) for visual maps
