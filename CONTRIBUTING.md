# 💛 Contributing to Bibble

Thanks for wanting to help make Bibble a cozier place to learn! Contributions of all sizes are welcome.

## 🌱 How to help

- **Share an idea:** Open an issue and tell us what would make Bibble more useful.
- **Report a bug:** Include what you expected, what happened, and steps to reproduce it.
- **Make a change:** Fork the repo, create a branch, and open a pull request with a short explanation.

## 🧑‍💻 Before you open a pull request

1. Install dependencies with `npm install`.
2. Run the app with `npm run dev` and check your changes.
3. Run `npm run lint`.
4. Describe what you changed in your pull request.

Please keep changes focused, use the existing cozy style, and remember that Bibble currently uses sample data rather than a backend.
